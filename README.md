# 1% Progress — Edition 078

Premium static newsletter with five articles, editorial visuals, a fully embedded "Editorial Room" critical-thinking escape game, animated reactions, public comments, likes/dislikes, Netlify Functions and Neon PostgreSQL persistence.

## Deploy

1. Upload this folder's contents to the root of the GitHub repository connected to Netlify.
2. Keep `DATABASE_URL` and `VISITOR_HASH_PEPPER` unchanged.
3. Set `NEWSLETTER_ID` to `edition-078`.
4. Trigger a fresh Netlify deployment.
